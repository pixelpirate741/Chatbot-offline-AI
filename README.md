🤖 ChatAI Free

A simple, clean, free offline AI-style chatbot built with Python and Kivy.

ChatAI Free has a modern messaging interface inspired by popular chat apps, while keeping the project lightweight and beginner-friendly.

✨ Features

- 💬 Modern chat interface
- 🤖 Offline chatbot responses
- 📱 Android/touch-friendly UI
- 🟢 Clean messaging bubbles
- ⏰ Message timestamps
- 🗑️ Clear chat button
- ⌨️ Keyboard support
- 💰 Completely free
- 🔑 No API key required
- 🌐 No internet connection required
- 🚫 No KivyMD dependency

🛠️ Built With

- Python
- Kivy
- "datetime"
- "random"

🚀 Getting Started

1. Install Python

Make sure Python is installed on your computer or Android Python environment.

2. Install Kivy

pip install kivy

3. Download the project

Clone this repository:

git clone https://github.com/YOUR-USERNAME/ChatAI-Free.git

Then open the project folder.

4. Run the app

python ChatAI_Free_Kivy.py

📱 Android

The app is designed with touch-friendly controls and can be run in a compatible Android Python/Kivy environment.

It does not require KivyMD.

🧠 How It Works

ChatAI Free currently uses a simple local response system.

When you send a message, the program checks what you typed and chooses an appropriate response.

For example:

You: Hello!

ChatAI: Hey! 👋

Or:

You: Tell me a joke

ChatAI: Why did the computer get cold?
It left its Windows open! 😂

Because the chatbot is offline, it doesn't have the same knowledge or intelligence as a large online AI model.
